# litevna

Замеры КСВ антенн на **LiteVNA 64** (50 кГц – 6.3 ГГц): ручная процедура на самом приборе и Python-скрипт на `pynanovna`.

## Быстрый старт (скрипт)

```bash
pip install -r requirements.txt
python3 vna_swr.py cal 860 880       # калибровка OPEN/SHORT/LOAD на порту 1
python3 vna_swr.py measure 860 880   # замер + таблица + csv
```

- Без аргументов диапазон 0.7–6 ГГц, 1001 точка (шаг 5.3 МГц, для узких полос мало).
- Для LoRa 869.525 МГц использовать узкий диапазон, например 860–880 МГц.
- Нужен доступ к `/dev/ttyACM0`: группа `uucp` (Arch) или `sudo`.
- Калибровка хранится в `litevna_<от>-<до>MHz.cal` и действует только на тот диапазон, на котором сделана.

## Процедура на приборе

1. **STIMULUS**: START/STOP на нужный диапазон.
2. **CALIBRATE → RESET**, затем:
   - **OPEN**: порт 1 пустой;
   - **SHORT**: заглушка ~0.6 Ом на порт 1;
   - **LOAD**: заглушка 50 Ом на порт 1.
   Все три только на **порт 1** (S11), не на порт 2.
3. **DONE** и сохранить в слот. Достать: **RECALL → слот**.
4. **DISPLAY → FORMAT → SWR** для КСВ (LOGMAG для return loss).
5. Проверка калибровки: на 50 Ом линия ровная ниже −40 дБ.

Калибровать нужно там, где потом подключается антенна: на самом порту или на конце кабеля/переходника.

## Предупреждения

- Вход прибора: **+10 dBm RF, 10 VDC max**. Усилитель, передатчик или антенну под передачей к VNA **не подключать**. КСВ усилителя мерить проходным КСВ/ватт-метром, а нагрузку усилителя (переходник + антенна) отдельно, с выключенным усилителем.
- Антенна без противовеса («резинка») зависит от «земли»: USB-кабель, ноутбук и рука меняют резонанс. Мерить на вытянутой руке или на подставке.

## Результаты замеров (2026-10-17)

| Антенна | Частота | Результат |
|---|---|---|
| Патч 2.4 ГГц, 9 dBi (с пробоинами) | 2.44 / 2.484 ГГц | КСВ ≈ 2.0 / 1.9, провал на 2.35 ГГц (−32 дБ) |
| Заводская «резинка» LoRa 868 | 868 МГц | КСВ 2.6–2.8, резонанс ≈ 935 МГц |
| Она же после растяжки пружины под колпаком | 868.25 МГц | КСВ 1.62, провал 852.5 МГц (пружина упругая, настройка уплывает) |
| Плоская антенна LoRa | 869 МГц | КСВ ≈ 2.0, резонанс ≈ 880 МГц (КСВ 1.1) |

Заметки: резонанс патча сдвигается вниз удлинением металла (≈1.5% длины на ~10 МГц на 870 МГц), вверх укорочением. Полоса 880–915 МГц это не LoRa 863–870, а сотовая связь.
